# elo-payroll-association — docs

The short map of this project:

1. **../CLAUDE.md** — the project catalog and the rules my engineering
   partner follows before any task. Source of truth for what's wired up.
2. **../Working Files/product-plan.md** — what we're building, the data
   model, and the two build blocks with Definition of Done.
3. **architecture/architecture.html** — how the CRM is built and the full
   data model, in one browser-openable page. Written after the plan.
4. **../.env.local** — environment keys. Ships as stubs; replace each
   YOUR_... value with the real key. Never committed.

Folders:
- **plans/** — build plans and step-by-step execution notes.
- **product/** — product specs, decisions, and positioning.
- **qa/** — test plans, QA checklists, and bug logs.
- **architecture/** — data model, system design, and technical decisions.

If anything here disagrees with CLAUDE.md, CLAUDE.md wins.
